
# 나만의 상식 퀴즈 게임

## 1. 프로젝트 개요
Python으로 만든 초등학생 상식 퀴즈 게임입니다.
터미널에서 퀴즈를 풀고 새로운 문제를 추가할 수 있습니다.

## 2. 퀴즈 주제와 선정 이유
주제: 초등학생 상식 퀴즈

동물, 과학, 수학, 생활 상식 등을 재미있게
공부할 수 있도록 이 주제를 선택했습니다.

## 3. 실행 방법
Python 3.10 이상이 필요합니다.

터미널에서 다음 명령어를 실행합니다.

python main.py

## 4. 주요 기능
1. 퀴즈 풀기
2. 새로운 퀴즈 추가
3. 퀴즈 목록 확인
4. 최고 점수 확인
5. 게임 종료
6. 잘못된 입력 처리
7. JSON 파일 자동 저장 및 불러오기

## 5. 파일 구조
quiz-game/
- main.py : 퀴즈 게임 프로그램
- state.json : 퀴즈와 최고 점수 데이터
- README.md : 프로젝트 설명서
- .gitignore : Git 제외 파일 설정

## 6. 데이터 파일 설명
state.json은 프로젝트 폴더에 저장됩니다.
UTF-8 형식으로 읽고 씁니다.

quizzes : 문제, 선택지 4개, 정답 번호를 담은 목록
best_score : 최고 점수(0~100), 기록이 없으면 null

파일이 없으면 기본 문제 5개를 생성합니다.
파일이 손상되면 기본 데이터로 초기화합니다.

## 7. 사용 기술
Python 3.10+
Git / GitHub
JSON
클래스 및 객체 지향 프로그래밍
